# REST API «Библиотеки» (v1)

Базовый адрес: `/api/v1`. Алиас без версии `/api` также поддерживается. Интерактивная документация: `/docs` (Swagger UI), `/redoc`; схема API — `/openapi.json`.

Формат запросов и ответов — JSON, кодировка UTF-8. Для защищённых маршрутов используется заголовок `Authorization: Bearer <access_token>`.

## Формат ошибок

Стандартный формат ошибки:

```json
{
  "detail": "Описание ошибки"
}
```

Основные HTTP-коды:

| Код | Значение |
|---|---|
| 400 | Некорректный запрос |
| 401 | Отсутствует или недействителен токен; неверные учётные данные |
| 403 | Недостаточно прав |
| 404 | Ресурс не найден или недоступен пользователю |
| 409 | Конфликт данных или недопустимое действие |
| 422 | Ошибка валидации |
| 429 | Превышен лимит запросов |
| 500 | Внутренняя ошибка сервера |

## Аутентификация

Все пути ниже указаны относительно `/api/v1`.

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | `/auth/register` | Гость | Регистрация по `username`, `email`, `password` |
| POST | `/auth/login` | Гость | Вход по имени пользователя или email и паролю |
| POST | `/auth/token` | Гость | OAuth2 password flow для авторизации через Swagger |
| POST | `/auth/refresh` | Гость | Обновление пары токенов |
| POST | `/auth/logout` | Гость | Отзыв refresh-токена |
| GET | `/auth/me` | Авторизованный пользователь | Получение текущего пользователя |

Роль пользователя назначается сервером, а не передаётся клиентом как доверенное значение.

## Каталог книг

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/books` | Гость | Список книг с поиском, фильтрацией и пагинацией |
| GET | `/books/search` | Гость | Поиск книг, включая поддерживаемый режим `smart` |
| GET | `/books/{id}` | Гость | Подробная информация о книге |
| POST | `/books` | Администратор | Создание книги |
| GET | `/genres` | Гость | Список жанров |

Параметры каталога могут включать `limit`, `offset`, `q`, `genre`, `author`, `year`, `sort` и `order`.

Стандартные параметры пагинации: `limit` — количество результатов, `offset` — смещение. Допустимые значения определяются API-валидацией.

Для авторизованного пользователя карточка книги может содержать данные о его библиотеке и оценке.

## Личная библиотека

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/library` | Авторизованный пользователь | Список записей личной библиотеки |
| GET | `/library/stats` | Авторизованный пользователь | Статистика чтения и оценок |
| POST | `/library` | Авторизованный пользователь | Добавление книги в библиотеку |
| PATCH | `/library/{entry_id}` | Авторизованный пользователь | Изменение статуса чтения |
| DELETE | `/library/{entry_id}` | Авторизованный пользователь | Удаление записи из библиотеки |

Поддерживаемые статусы:

- `want_to_read` — хочу прочитать;
- `in_progress` — читаю;
- `read` — прочитано.

Записи чужой библиотеки недоступны пользователю.

## Оценки

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/books/{book_id}/rating` | Авторизованный пользователь | Получение собственной оценки |
| POST | `/books/{book_id}/rating` | Авторизованный пользователь | Создание или сохранение оценки |
| PATCH | `/books/{book_id}/rating` | Авторизованный пользователь | Частичное изменение оценки |
| GET | `/books/{book_id}/ratings` | Гость | Просмотр оценок книги с пагинацией |

Оценка включает три целочисленных критерия от 1 до 10: `plot`, `characters` и `style`.

Итоговая оценка вычисляется как среднее трёх критериев и округляется до одного знака после запятой. Оценивать можно только книгу со статусом `read`.

## Рекомендации

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/recommendations` | Авторизованный пользователь | Получение рекомендаций |
| POST | `/recommendations/feedback` | Авторизованный пользователь | Создание или обновление обратной связи |

Обратная связь принимает значения `helpful` и `not_helpful`. Ответ рекомендаций может включать сведения о книге, объяснение рекомендации и признаки, использованные при подборе.

## Служебные маршруты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/health` | Проверка состояния приложения и доступности зависимостей |
| GET | `/metrics` | Метрики Prometheus |

Некоторые служебные маршруты также могут быть доступны через префиксы `/api` и `/api/v1` в зависимости от конфигурации приложения.

## Примечание

Этот документ описывает ожидаемый контракт API. Фактические маршруты, поля ответов и ограничения следует сверять с текущими роутерами, схемами Pydantic и документацией Swagger.
