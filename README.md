# Библиотека

Веб-приложение для управления библиотекой книг: просмотр каталога, ведение личной библиотеки, выставление оценок и получение рекомендаций.

## Технологии

- **Backend:** Python, FastAPI, SQLAlchemy, Alembic.
- **База данных:** PostgreSQL.
- **Кэширование и ограничение запросов:** Redis.
- **Frontend:** React, TypeScript, Redux Toolkit.
- **Запуск:** Docker Compose, Nginx.

## Возможности

- Регистрация, авторизация и обновление токенов.
- Просмотр каталога книг, поиск и фильтрация.
- Управление личной библиотекой и статусами чтения.
- Оценивание прочитанных книг.
- Рекомендации книг.
- Проверка состояния приложения и сбор метрик.

## Запуск проекта

Перед запуском убедитесь, что установлен Docker Desktop с поддержкой Docker Compose.

1. При необходимости создайте файл `backend/.env` на основе `backend/.env.example`.
2. Проверьте настройки подключения к PostgreSQL и Redis в конфигурации.
3. Запустите сервисы через Docker Compose.
4. Дождитесь готовности контейнеров.

Если контейнеры уже запущены, **не перезапускайте их сейчас**: сначала завершим проверку конфликтов.

## Адреса

- **Веб-приложение:** http://localhost:8080
- **Swagger API:** http://localhost:8000/docs
- **Проверка состояния:** http://localhost:8000/health
- **Метрики:** http://localhost:8000/metrics

Доступность Swagger зависит от настроек приложения.

## Структура проекта

```text
backend/
  app/
    routers/       # API-маршруты
    services/      # Бизнес-логика
    config.py      # Настройки приложения
    database.py    # Подключение к БД
    models.py      # Модели SQLAlchemy
    schemas.py     # Схемы API
    main.py        # Инициализация FastAPI
  alembic/         # Миграции базы данных
  requirements.txt
  Dockerfile

frontend/
  src/
    api/           # Клиент API
    components/    # Компоненты интерфейса
    pages/         # Страницы приложения
    store/         # Redux
    styles/        # Стили
    types/         # Типы TypeScript
  Dockerfile

docker-compose.yml
```

## API

Основной префикс API — `/api/v1`. Также может использоваться префикс `/api`.

Подробное описание маршрутов находится в `docs/api.md`.

## База данных

Структура базы данных управляется миграциями Alembic. Перед применением миграций убедитесь, что версия моделей и миграций согласована.

## Оптимизация

При анализе производительности следует сравнивать показатели до и после изменений при одинаковых условиях нагрузки. Важные метрики: время ответа, пропускная способность, количество ошибок и использование ресурсов.
